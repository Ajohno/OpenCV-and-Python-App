## End Result: 

I want to create a Python desktop app that I can put on my computer’s task bar to allow me to easily start it whenever I want. This app will use the face detection to detect on launch either if someone is looking at the screen (or if possible if specifically I am looking at the screen) this will bring the user to the main interface of the app.

The user will be able to choose between whether they use hand gestures or their eyes to control the mouse. They will be able to change this at anytime in the app.

If they use their eyes to control it they will have the face detection to verify the face is there. If they use their hands they will have a detection to verify it is there.

The user will be able to control videos by using hand gestures for pausing, playing and changing the volume of videos.

This will allow someone to for example navigate YouTube or Netflix while laying down or sitting away from a laptop connected to the television without directly touching the laptop.
